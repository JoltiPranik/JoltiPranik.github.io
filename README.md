# Гайд по репозиторию
1. В папке image содержатся изображение для документаций, баг-репортов, и гитхаб-пейджес
2. В папках с названиями игр распологается экспорт под веб версию игр
3. В папке Godot_games находятся проекты в разработке
4. В папке Documents находится документация к гитхаб-пейджес и играм
5. В папке Testing находятся баг-репорты, тестовая документация, чек-листы, тест-кейсы
